# Synapse
Synapse é um motor de testes de estresse de rede em Python, projetado para alta performance. Utiliza Multiprocessing para superar o GIL e Raw Sockets com a flag IP_HDRINCL para forja de pacotes em Layer 3. Implementa IP Spoofing dinâmico e payloads aleatórios, permitindo a validação de firewalls e a resiliência de infraestruturas TCP/IP.
